Linear Regression Parametric Baseline Summary

Multiple Linear Regression with Ridge regularization (alpha=0.1) provides a deterministic parametric baseline for continuous yield modeling. While linear specifications model overarching regional elevation-pressure trends effectively, they fail to capture severe non-linear heat-stress saturation points, explaining why non-linear tree ensembles outperform linear models by over 25% in predictive fidelity.
